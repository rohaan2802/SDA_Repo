## Course Overview

Software Design and Analysis (CS-3004) at FAST-NUCES Islamabad, Fall 2025. The repository has 12 lectures, coding lectures on Java Swing and JDBC, assignments and project deliverables with my Java code, the Inventory and Stock Management System project, a past paper, practice material, four textbooks and my study notes.

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – OOP & analysis** | Software process, UML overview, OOP principles and layered architecture. |
| **Unit 2 – Requirements** | Use case diagrams, brief and fully dressed use cases, and the two-column format. |
| **Unit 3 – Modelling** | Domain models, system sequence diagrams, sequence diagrams and class diagrams. |
| **Unit 4 – Design & Java** | GRASP and GoF patterns, Java Swing and JDBC. |

## Running the Code

```bash
git clone https://github.com/rohaan2802/SDA_Repo.git
cd SDA_Repo/Assignments/i222327_B
javac -d out src/module-info.java src/banking/*.java
java -p out -m i222327_B/banking.AccountManagementSystem
```

- **Eclipse:** *File → Import → Existing Projects into Workspace* and pick `Assignments/i222327_B`.
- **IntelliJ IDEA:** open `Assignments/Java_Swing_Screen` or `Coding Lectures/test_database`. The JDBC example needs SQL Server and the bundled `mssql-jdbc` jar on the classpath; set your own server, user and password in `Main.java`.
- Build output (`bin`, `out`, `.class` files) is not stored in the repository; the IDE recreates it on the first build.
